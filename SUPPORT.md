# Support

This is a small educational C program maintained on a best-effort basis.

Read the [installation guide](docs/installation.md), [troubleshooting guide](docs/troubleshooting.md), and [FAQ](docs/faq.md) first. Include compiler, operating system, command, and sanitized output when reporting a reproducible problem.

Never attach `accounts.dat` containing personal or financial data. Report vulnerabilities through [SECURITY.md](SECURITY.md).
