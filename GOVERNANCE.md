# 🏛️ Project governance

## Mission

This repository is maintained as an educational C programming project. Its purpose is to help learners explore structures, arrays, functions, loops, console I/O, and basic file persistence. It is not a banking product.

## Maintainer

Repository owner: Brajesh Kumar, GitHub [@Brajesh31](https://github.com/Brajesh31).

## Decision principles

Changes are evaluated for correctness, clarity, learning value, maintainability, and honest documentation. Security and memory-safety concerns take precedence over cosmetic feature requests.

## Contributions

Contributions are welcome through issues and pull requests. Follow [CONTRIBUTING.md](CONTRIBUTING.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Security

Report suspected vulnerabilities privately using the process in [SECURITY.md](SECURITY.md). Do not disclose real account data.

## Roadmap

Future items are proposals until implemented, tested, and merged. Documentation must keep the distinction between current behaviour and target design clear.
