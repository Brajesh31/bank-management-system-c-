# FAQ

## Is this a real banking application?

No. It is an educational C console demonstration.

## Where are records stored?

In `accounts.dat`, relative to the process working directory.

## How many accounts are supported?

The current fixed array supports up to 100 records.

## Does it use a database?

No. It uses a local raw binary file.

## Where should I report security problems?

Use the private reporting process in [SECURITY.md](../SECURITY.md).
