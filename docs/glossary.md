# 📖 Glossary

| Term | Definition |
|---|---|
| Account | One instance of the C `Account` structure |
| Account count | Number of active entries in the global array |
| Account number | Integer used by current lookup functions |
| Active prefix | Array entries from zero to `accountCount - 1` |
| Array capacity | Maximum number of records, currently 100 |
| Binary file | File containing raw bytes rather than readable text |
| C11 | ISO C language standard revision used in recommended build commands |
| Deposit | Increase to a stored balance |
| Floating point | Numeric representation used by the current `float` balance field |
| Global state | Data declared outside functions and shared across the program |
| Linear search | Inspect each element sequentially until a match is found |
| Persistence | Retaining data beyond the running process |
| Serialization | Encoding program values into a defined storage representation |
| Transaction ledger | Historical record of financial events, not implemented here |
| Working directory | Directory used to resolve relative paths |
| Withdrawal | Decrease to a stored balance after a comparison |
