# 🗺️ Diagram catalogue

The following Mermaid sources are editable. GitHub can render Mermaid code blocks in Markdown, and these `.mmd` files can be used in compatible diagram tools.

| Diagram | File | Purpose |
|---|---|---|
| System context | [system-context.mmd](system-context.mmd) | User, executable, source, and local file boundary |
| Application flow | [application-flow.mmd](application-flow.mmd) | Main menu loop and function dispatch |
| Create sequence | [create-account-sequence.mmd](create-account-sequence.mmd) | Account creation and append |
| Deposit sequence | [deposit-sequence.mmd](deposit-sequence.mmd) | Lookup and balance mutation |
| Withdrawal flow | [withdrawal-sequence.mmd](withdrawal-sequence.mmd) | Balance decision and withdrawal result |
| Delete flow | [delete-account.mmd](delete-account.mmd) | Search and array compaction |
| Persistence sequence | [persistence-sequence.mmd](persistence-sequence.mmd) | Startup load and exit save |
| Data flow | [data-flow.mmd](data-flow.mmd) | Input, memory, and file paths |
| Component map | [component-map.mmd](component-map.mmd) | Current functions and shared state |
| Proposed data model | [future-data-model.mmd](future-data-model.mmd) | Future account/transaction relationship |

The future model is explicitly a proposal, not part of current code.
