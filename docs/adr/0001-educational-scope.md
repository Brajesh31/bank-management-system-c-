# ADR 0001: Maintain educational scope

- **Status:** Accepted
- **Date:** 2026-11-16

## Context
The repository contains a single C source file, terminal menu, fixed account array, and local binary persistence. There is no service layer or network interface.

## Decision
Maintain and describe the project as an educational C programming example. Do not imply that it is a secure banking platform.

## Consequences
The project remains easy to compile and study. Documentation must state the current limitations. Any attempt to handle real financial data requires a separate architecture and qualified security review.
