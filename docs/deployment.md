# Deployment

There is no server deployment for this program. Distribute a compiler-built executable only for controlled educational demonstrations.

Before sharing a build, compile with warnings, scan the source and binary, verify the build from a clean checkout, and provide a private writable data directory. Do not run it with real financial records or on shared machines.

For a production-grade service, replace local binary storage with an authenticated, encrypted, transactional backend and perform a formal security review.
