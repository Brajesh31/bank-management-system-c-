# User interface

The project has no HTTP or library API. Its terminal menu provides these operations:

| Option | Operation |
| --- | --- |
| 1 | Create account |
| 2 | View accounts |
| 3 | Deposit money |
| 4 | Withdraw money |
| 5 | Delete account |
| 6 | Save and exit |

The local persistence interface is the raw `Account` array written to `accounts.dat`.
